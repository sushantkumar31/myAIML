# myAIML

myAIML is a notebook-based learning project for practical machine learning foundations. It moves from core math concepts to data analysis, visualization, and regression workflows so you can follow the full path from theory to implementation.

## What's Inside

- `phase1.ipynb` focuses on the mathematical building blocks of machine learning.
  - Linear algebra for vectors, matrices, dot products, and eigen concepts
  - Calculus for numerical derivatives, chain rule, and gradient descent
  - Probability and statistics for distributions, expectation, covariance, and Bayes' theorem
  - Information theory for entropy, cross-entropy, and KL divergence

- `phase2.ipynb` covers hands-on data science practice in Python.
  - NumPy fundamentals and vectorized computation
  - Pandas data cleaning, filtering, grouping, and feature engineering
  - Matplotlib and Seaborn visualizations
  - Exploratory data analysis and preprocessing examples

- `phase3.ipynb` covers regression workflows end to end.
  - Linear regression from scratch and with scikit-learn
  - Logistic regression with from-scratch and scikit-learn implementations
  - Dataset-driven exercises using `tips` and `titanic`
  - Model evaluation, coefficients, residuals, and comparison plots

## Prerequisites

- Python 3.13 or newer
- Jupyter Notebook or Jupyter support in VS Code
- Dependencies listed in `pyproject.toml`
  - `ipykernel`
  - `matplotlib`
  - `numpy`
  - `pandas`
  - `scikit-learn`
  - `seaborn`

## Clone The Repository

```powershell
git clone <repository-url>
cd myAIML
```

Replace `<repository-url>` with the URL of your GitHub, GitLab, or local Git remote.

## Setup

1. Create a virtual environment.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install the project in editable mode.

```powershell
pip install -e .
```

3. Launch Jupyter.

```powershell
jupyter notebook
```

If you prefer VS Code, open the workspace and run the notebooks directly in the editor after selecting the `.venv` interpreter.

## How To Use

1. Start with `phase1.ipynb` to build intuition around the math behind machine learning.
2. Continue with `phase2.ipynb` to practice data handling and visualization.
3. Finish with `phase3.ipynb` to study regression, training loops, and model evaluation.
4. Run cells in order so that intermediate variables and figures are created in the expected sequence.
